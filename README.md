An entry for the [make.fun bounty "Sum up 24 November's world news in one image"](https://make.fun/bounty/news-image-20261124).

`main.py` (Python 3.13, standard library only) writes the front page to
`/output/entry.png`: a PIL-drawn newspaper front page, "THE WORLD TODAY —
TUESDAY 24 NOVEMBER 2026", 1024×1024 PNG, summing up five real stories of
24 November 2026 with their sources.

Run it with `mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py`.
